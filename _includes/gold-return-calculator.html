Gold pricing, costs and sources
  • The World Bank: Commodity Price Data (Pink Sheet) quotes nominal US dollars per troy ounce. From June 2025 it uses a spot average of daily rates; earlier observations use the London afternoon fixing, 99.5% fine. See the workbook’s Description sheet for suppliers and historical definitions.
  • Euro gold prices equal the dollar price divided by the ECB’s monthly-average US dollars per euro. The ratio of these two averages is used; it is not an average of daily euro gold prices. USD uses the original dollar series. The selected currency applies to every contribution as well as the result.
  • A lump sum buys once in the start month. Monthly buying includes both selected months, with each payment buying at that month’s average price. The last payment earns no return before valuation. Month-end dates are used only for the holding-period maths (365-day CAGR/XIRR), not as exact trade dates.
  • Real EUR figures use euro area HICP; real USD figures use US CPI-U, seasonally adjusted, via FRED. Values and each contribution are restated in the selected valuation month’s money. {% for m in gd.gold_source.cpi_filled %}US CPI for {{ m | append: "-01" | date: "%B %Y" }} is an estimate using the geometric midpoint of adjacent months, following this site’s existing CPI convention.{% endfor %}
  • No dividends, interest or other income are added. Storage, insurance, dealer spreads, transaction and currency-conversion charges, fund fees and taxes are excluded. This does not model the return on a particular coin, bar or fund.
